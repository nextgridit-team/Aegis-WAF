# Aegis WAF console design

The console serves administrators bringing applications online. Its primary workflow is certificate first, proxy host second. The default page is Certificates; automatic issuance status lives beside the inventory. Certificate authorities are a secondary destination. A new ACME request guides the administrator through authority registration, explicit terms acceptance, domains, and DNS/port-80 prerequisites. Successful issuance exposes Connect site with certificate and hostnames already selected.

The visual system uses white surfaces, a pale slate workspace, charcoal text, and a restrained evergreen accent. A compact persistent sidebar, readable tables, native dialogs, consistent outlined icons, and quiet status badges support recurring administration. No external fonts or decorative imagery are loaded. On mobile, navigation moves to a horizontal strip and dialogs fit the viewport; data tables retain accessible horizontal scrolling.

All settings persist through the authenticated Go API and PostgreSQL. Issuance state polls every four seconds while the page is visible and no editing dialog is open. Forms preserve input on failure; authority changes invalidate prior terms acceptance. The interface distinguishes queued, issuing, retrying, valid, and expired certificates. Secrets remain server-side. A certificate is only described as ready after the backend reports valid material.
