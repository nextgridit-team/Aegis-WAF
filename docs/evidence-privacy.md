# Evidence privacy and residency

Traffic sampling is disabled by default. Each application's Traffic capture form selects a small allowlist of query/header/JSON fields, optional paths, sampling rate and retention. Credential selectors are rejected. Built-in redaction removes common tokens and path identifiers; it cannot recognize all personal data.

**Additional redaction patterns** supplies up to eight bounded RE2 expressions per application. If a pattern matches a captured value, the whole value becomes `[redacted]` before serialization and PostgreSQL insertion. Patterns compile when configuration loads and execute in the background evidence worker. This hook affects evidence, not traffic forwarded upstream. Invalid expressions cannot replace the working configuration. Redacted facts are unknown to offline replay. Changing patterns affects future samples; existing records retain their prior contents and expiry.

Evidence and access logs stay in the operator's PostgreSQL deployment, its replicas and backups, and the administrator's browser when viewed. Aegis does not select a region or provide storage-residency guarantees. Provider connection/model-list checks do not submit traffic. Country enrichment downloads a static database rather than sending visitor IPs to a lookup service. Future model-based review must require explicit data-sharing configuration.

Access metadata still includes resolved client IP addresses, timestamps, application IDs and outcomes. That metadata is not anonymized by the evidence redaction hook. Evidence content is not encrypted by the private-key encryption feature; use appropriate deployment-level encrypted storage and access controls. Expired evidence is hidden by the API and removed in bounded background batches while PostgreSQL is available. Database outages can delay physical deletion; backups have their own operator-controlled retention. Metadata logs do not currently have automatic retention. Sampling, redaction and expiry alone do not establish compliance with a privacy standard.
